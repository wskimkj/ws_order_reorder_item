주문 데이터 업로드

엑셀 파일(.xlsx)을 업로드하면 모든 시트의 상단 10개 행을 검사하여 주문 데이터 헤더를 자동으로 찾습니다. 시트명과 시트 개수는 상관없습니다.

표준 발주서 양식 다운로드 양식이 다른 경우 내려받아 데이터를 옮긴 후 업로드해 주세요.
엑셀 파일(.xlsx)을 이곳에 드래그하거나 클릭해서 선택하세요

업로드 기록

업로드한 파일명, 등록 건수, 업로드 일시와 로그인 계정을 확인합니다.

업로드 기록을 불러오려면 새로고침을 눌러주세요.

출고일을 선택해 주세요

엑셀에 출고일이 입력되지 않은 데이터가 있습니다. 선택한 날짜를 누락된 행에 자동으로 입력한 뒤 업로드합니다.
